# Carpeta de audios

Colocá acá los archivos de audio a transcribir. El watcher los detecta automáticamente.

## Formatos soportados

`.ogg` `.opus` `.mp3` `.m4a` `.wav`

## Cómo bajar un audio de WhatsApp

**Desde WhatsApp Web:**
1. Abrí el chat en web.whatsapp.com
2. Pasá el mouse sobre el mensaje de voz → ícono de descarga ↓
3. Guardá el archivo en esta carpeta

**Desde WhatsApp Desktop (Mac):**
1. Clic en `...` sobre el mensaje → "Guardar en Descargas"
2. Mové el archivo desde `~/Downloads/` a esta carpeta

## Resultados

Las transcripciones y resúmenes se guardan en `salidas/` con el mismo nombre del audio y extensión `.txt`.
